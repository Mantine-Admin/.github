## What we're building

- **Headless core**: data and auth providers, a resource registry and controllers on top of TanStack Query, Router and Table.
- **Mantine UI layer**: layouts, list/create/edit/show views, fields and inputs.
- **Reference data providers**, starting with a simple REST provider.

> [!NOTE]
> Mantine Admin is in early development. Public APIs will change until `1.0`.

## How this organization works

Most day-to-day work here is done by AI coding agents inside strict guardrails:
deterministic CI, risk classes per change, and human approval for everything critical.
Agents propose; rules and humans decide. Read [GOVERNANCE.md](https://github.com/Mantine-Admin/.github/blob/main/GOVERNANCE.md)
and our [AI policy](https://github.com/Mantine-Admin/.github/blob/main/AI_POLICY.md) to learn more.

Questions and feature ideas go to [Discussions](https://github.com/orgs/Mantine-Admin/discussions).
Found a vulnerability? Please follow our [security policy](https://github.com/Mantine-Admin/.github/blob/main/SECURITY.md).
